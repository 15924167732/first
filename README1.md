# FF14战斗分析器

## 项目概述

FF14战斗分析器是一个专门用于分析《最终幻想14》(FF14)战斗日志的工具。它能够实时监控和离线分析ACT日志文件，提取战斗中的关键数据，如伤害输出(DPS)、治疗量(HPS)、死亡事件等，并以直观的图形界面展示分析结果。

该工具旨在帮助玩家更好地理解战斗表现，优化角色配置和团队策略，提升游戏体验。

## 环境要求

- Windows操作系统（推荐Windows 10或更高版本）
- Python 3.8或更高版本
- ACT (Advanced Combat Tracker) 已安装并配置好
- 相关的FF14 ACT插件（如FFXIV Plugin）

## 安装与运行

1. 确保已安装Python 3.8+
2. 克隆或下载本项目代码到本地
3. 安装所需的依赖库（如果有的话）
4. 运行`main.py`启动程序

程序启动时会检查是否以管理员权限运行，如果不是，会自动请求提升权限。同时还会检查是否已有实例在运行，避免重复启动。

首次运行时，程序会显示启动配置对话框，允许用户设置是否自动启动ACT以及指定ACT启动文件路径。

## 项目结构

项目主要分为以下几个模块：

- `main.py`: 程序入口点，负责初始化和启动应用
- `core/`: 核心功能模块
  - `analyzer.py`: 离线分析ACT日志文件
  - `monitor.py`: 实时监控ACT日志文件
- `gui/`: 图形用户界面模块
  - `main_window.py`: 主窗口界面
  - `overlay_window.py`: 悬浮窗界面
  - `startup_dialog.py`: 启动配置对话框
- `utils/`: 工具和常量模块
  - `config.py`: 配置管理
  - `constants.py`: 常量定义
- `assets/`: 静态资源文件（如图标等）
- `docs/`: 文档资料

## 配置说明

程序的配置存储在`config.json`文件中，包含以下主要配置项：

- `auto_start_act`: 是否自动启动ACT (布尔值，默认为true)
- `act_path`: ACT启动文件路径 (字符串，默认为空，使用默认路径)
- `minimize_act`: 是否最小化ACT窗口 (布尔值，默认为true)

用户可以通过启动配置对话框修改这些设置，也可以直接编辑`config.json`文件。

## 日志解析说明

本工具支持解析和分析FF14的ACT日志文件，主要包括以下功能：

1. **实时监控**: 通过`core/monitor.py`模块实时监控ACT日志文件的变化，动态更新当前战斗数据。
2. **离线分析**: 通过`core/analyzer.py`模块对历史日志文件进行完整分析，提取所有战斗信息。
3. **数据展示**: 在GUI界面中展示分析结果，包括伤害输出(DPS)、治疗量(HPS)、死亡事件等。
4. **支持的日志类型**: 
   - 03行 (0x03): 添加实体
   - 21行 (0x15): 单体技能
   - 22行 (0x16): 群体技能
   - 25行 (0x19): 实体死亡
   - 260行 (0x104): 进战状态
   - 265行 (0x109): 副本区域变更

日志文件路径可以在程序启动时通过配置对话框设置，也可以在主界面中修改。默认会自动查找最新的日志文件。

# FF14 战斗分析器 - 项目结构（程序清单）

## 🚀 快速启动
1.  **前提**：确保已安装 [ACT](https://act.diemoe.net/) 并开启网络日志，悬浮窗。
2.  **安装依赖**：`pip install -r requirements.txt`
3.  **运行程序**：FF14BattleAnalyzer.exe

## 📁 项目结构清单

### 🧠 核心模块 (`core/`)
处理ACT日志分析和实时监控的核心逻辑。
| 文件 | 职责 |
| :--- | :--- |
| `analyzer.py` | 离线分析ACT日志文件，解析战斗事件，生成副本报告。 |
| `monitor.py` | 实时监控日志文件变化，动态更新战斗数据流。 |

### 🖥️ 图形界面模块 (`gui/`)
基于 PyQt6 构建的用户界面。
| 文件 | 职责 |
| :--- | :--- |
| `main_window.py` | 主窗口，展示战斗列表、详细数据、提供控制面板。 |
| `overlay_window.py` | 实时悬浮窗，显示DPS/HPS/死亡次数等关键指标。 |
| `startup_dialog.py` | 启动配置对话框，设置ACT路径和启动选项。 |

### ⚙️ 工具模块 (`utils/`)
提供底层支持功能。
| 文件 | 职责 |
| :--- | :--- |
| `config.py` | 配置管理类，负责 `config.json` 的读写。 |
| `constants.py` | 定义全局常量：职业映射、日志类型、UI尺寸、程序版本。 |

### 📄 根目录文件
| 文件 | 职责 |
| :--- | :--- |
| `main.py` | **程序入口**。初始化配置，启动ACT，加载主界面。 |
| `requirements.txt` | **Python依赖包清单**。 |
| `config.json` | **用户配置文件**（自动生成）。存储ACT路径、窗口设置等。 |
| `report_basic.json` | 存储基础战斗报告数据（示例或缓存）。 |
| `summary.json` | 存储战斗摘要或统计数据。 |
| `7.0 ACT 日志指南.md` | ACT日志格式的技术参考文档。 |

## 🔧 开发与构建

- **打包命令**：`pyinstaller --onefile --windowed --icon=icon.ico main.py`
- **版本管理**：项目版本定义于 `constants.py` 的 `__version__` 变量中。
